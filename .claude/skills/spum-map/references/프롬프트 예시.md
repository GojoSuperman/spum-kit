# 검증된 프롬프트

실제로 성공한 것만 적는다. 글자 수를 함께 남긴다 — **520자를 넘으면 `504` 가 나기 쉽다.**

## 우주선 실내 (446자, 성공)

```
Top-down orthographic spaceship interior floor plan, one continuous scene, game map art.
Bridge top center with consoles and a starry viewport. Central vertical corridor down to the engine room.
Upper left crew bunks, lower left mess hall, upper right medbay, lower right cargo crates.
Bottom center engine room with a glowing cyan reactor.
Metal deck plating, dark ribbed bulkheads, yellow warning stripes.
Clean detailed illustration, soft shadows, cool industrial palette.
No text, no people, no UI. Square, aligned to a 32x32 grid.
```

## 중세 여관 1층 (446자, 성공)

```
Top-down orthographic medieval tavern ground floor, one continuous scene, game map art.
Bar counter with stools top right, kitchen hearth behind it.
Large stone fireplace on the left wall with benches.
Main hall of wooden tables, chairs and long benches.
Staircase to the upper floor bottom right, barrel storage bottom left.
Warm wooden plank floor, stone walls, rugs, hanging lanterns.
No text, no people, no UI. Square, aligned to a 32x32 grid.
```

> 같은 여관을 507자로 썼을 때는 `504` 가 났다. 배치를 남기고
> `with stools at the top right` → `with stools top right`,
> `a cooking hearth` → `hearth` 처럼 수식어만 줄여 446자로 만들자 통과했다.

## 통행 마스크 (스크립트가 자동으로 넣는다)

```
Convert the reference into a flat two-tone navigation mask, same layout and grid alignment.
Pure WHITE for ground a person can walk on: floors, paths, grass, lawns, dirt, rugs.
Pure BLACK for everything blocked: walls, furniture, beds, tables, chairs, counters, crates, barrels, stairs, bushes, potted plants,
fireplaces, stalls, water, rivers, canals, ponds, fountains, pits.
Hard edges, no anti-aliasing, no grey, no gradients, no text, no icons.
Keep the same shapes and positions. Square image on a 32x32 grid.
```

514자. 두 번 고쳤다 (2026-08-20 실측):

| 증상 | 고친 것 |
|---|---|
| 물 88칸 중 73칸이 통행으로 잡혀 캐릭터가 수로를 걸어 건넜다 | 막을 것에 `water, rivers, canals, ponds, fountains, pits` 추가 → 다음 맵에서 55칸 중 1칸(2%)으로 |
| 잔디 101칸 중 1칸만 통행이라 정원인데 길만 걸을 수 있었다 | 걸을 것에 `grass, lawns, dirt, rugs` 를 명시하고 `plants` 를 `bushes, potted plants` 로 좁힘 |

조감도를 SOURCE 로 넣어 **img2img** 로 돌리기 때문에 구조가 유지된다.
이걸 안 쓰고 씬 픽셀만으로 통행을 추정하면 **실패한다** —
바닥(밝기 77~110)과 설비(53~82)가 겹쳐 통행 0칸이 나왔다.

## 쓸 때의 요령

- 구역은 **3~6개**가 적당하다. 너무 많으면 각 구역이 뭉개진다.
- 위치를 `top right` · `bottom center` · `left wall` 처럼 **명시**한다.
- 바닥 재질을 밝게 잡으면 마스크가 정확해진다 (나무·세라믹 > 어두운 금속).
- `no people` 을 빼면 사람이 들어가고, 그 칸이 장애물로 잡힌다.
